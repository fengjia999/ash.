# Settings paper-ball texture

`settings-crumpled-paper.webp` replaces the geometric paper-ball SVG in the
settings page. Generated with the built-in imagegen tool using the user's
crumpled-paper photograph as an edit target; its transparent alpha is preserved
in the locally served WebP (quality 85, alpha quality 100).

Final prompt:

> Use case: background-extraction. Asset type: transparent UI sticker for a warm paper-themed settings page. Edit target: attached crumpled paper photograph. Remove ONLY the white background and retain the same crumpled paper, sharp irregular silhouette, fine folds, neutral ivory gray colors, lighting and orientation. Genuine transparent alpha background, including outside contour and any open gaps. Center subject with small transparent margins; no white rectangle, no text, no added objects, no round-ball redesign. Preserve photographic material texture.

The image is decorative: the native details/summary control and its text label
remain the accessible configuration toggle. The URL includes the dashboard's
static version, so future replacements can be deployed without stale textures.
