# 记忆片段

启用记忆后，在「其它 → 记忆片段」选择提取供应商和模型。后台也支持独立设置 `FRAGMENT_EXTRACT_API_URL`、`FRAGMENT_EXTRACT_API_KEY`、`FRAGMENT_EXTRACT_MODEL`。提取使用 OpenAI 兼容的 Chat Completions 接口。

在网关托管的会话中，助手的最终文字回复与待提取标记同时保存。默认每 3 轮处理一批，间隔可在「其它」调整。切换会话后后台也处理剩余轮次。首次安装从新完成的回复开始。提取读取人格提示词、启用的常驻记忆、双方名字及本批对话，以助手第一人称写作，在入库时选择情绪、里程碑、日常、计划中的一个或多个类别。后台可以重估重要度、把相关片段整合为一条，合并与标记处理完成在同一事务内提交。

「记忆」按时间展示片段，可按类别筛选或搜索，常驻记忆从同页入口打开。在「召回设置」打开跨对话记忆后，聊天时按话题类别和词项匹配片段，在字符预算内最多选 3 条。召回部分放在真实用户消息开头，以 `<memories>` 包裹并空一行。网关托管的消息历史保存实际发送的片段，后续请求可复用缓存前缀。当前上下文中已有的片段及其合并来源会从候选中排除。窗口滚动移出后允许再次召回。

## 外部前端

在支持远程 MCP 的前端填写网关地址加 `/mcp`，使用 `Authorization: Bearer <GATEWAY_SECRET>`。启用记忆后可调用以下工具。

| 工具 | 用途 |
| --- | --- |
| `core_memory` | 完整读取有效的固定与流动记忆，仅对外提供 |
| `query_diary` | 按主题查询、列出近期日记或按 ID 读取全文 |
| `write_diary` | 在对话将结束时主动写日记 |
| `recall_fragments` | 检索相关记忆，可传入类别 |
| `write_fragment` | 随时主动写下未来值得知道的事情，写入时选择类别 |

外部前端直接写入的片段立即可查，后台提取模型配置好后参与整理。

### URL 密码连接

在 VPS 的 Ash 进程或容器环境中设置独立的 `MCP_SECRET`，重启服务，然后在外部前端填写 `https://你的Ash域名/mcp/你的MCP_SECRET`。前端认证方式选择「无认证」：Ash 会校验地址中的密码。此密码只用于对外记忆工具，独立于后台密码 `DASHBOARD_PASSWORD` 和旧请求头密钥 `GATEWAY_SECRET`。

建议使用随机的字母、数字、下划线或短横线组成的长密码（例如运行 `openssl rand -hex 24` 生成），不要包含 `/`、`?`、`#`，不要使用保留路径名 `refresh-tools`。没有配置 `MCP_SECRET` 时 URL 密码入口关闭；更换它并重启即可让旧链接失效。Docker 部署要确保变量实际传入容器。

反向代理需将 `/mcp` 及 `/mcp/*` 转发到 Ash。完整链接等同密码，请私下保存。Ash 自身的访问日志会隐藏该路径中的密码；反向代理的访问日志也应对 `/mcp/*` 隐藏路径或关闭记录。

OAuth 已移除，旧 OAuth 环境变量可以删除，旧令牌不再有效。已创建的 OAuth 数据表不再使用，本次更新不删除数据库中的历史数据。原有 `Authorization: Bearer <GATEWAY_SECRET>` 配合 `/mcp` 的方式继续可用，内部日记读取和片段回忆工具保持原样。

记忆页可以在片段、固定和流动三个视图间切换。在片段视图点「写片段」，填写正文并选类别即可预置记忆。每条片段的「编辑」可以修改正文和类别，也可以删除该条片段。后台整理同时读取最多 12 条相关片段和 12 条近期片段，重合项只读取一次。聊天自动召回在配置提取模型后使用同一模型从最多 20 个候选中逐条判断是否对题，允许返回零条；重排超时或结果无效时本轮跳过注入。目录和 MCP 主动搜索直接返回检索结果。
